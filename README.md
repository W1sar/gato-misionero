# 🐱 Gato Misionero

Minijuego hecho con HTML, CSS y JavaScript puro (sin librerías).

Movés al gato para atrapar mates 🧉 y pescados 🐟 y esquivar las piedras 🪨. Tenés 3 vidas y la velocidad aumenta a medida que sumás puntos. El récord se guarda en tu navegador.

## Cómo jugar
Abrí `index.html` en tu navegador. Controles: dedo, mouse o flechas ← →.

## Qué practiqué
- Canvas 2D y game loop con `requestAnimationFrame`
- Detección de colisiones
- Eventos de puntero y teclado
- Diseño responsive
